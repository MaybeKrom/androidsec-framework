Android APK assessment

Find the weaknesses before someone else does.

androidsec reads an APK, runs the checks you choose, and opens an HTML report mapped to OWASP MASVS. You can also decompile that APK, browse the files, and rebuild it. Dynamic checks wait until you select a device and confirm you are authorized to test it. Static checks cover the manifest, permissions, exported components, secrets, crypto, storage, network settings, and WebView use.

Start an assessment

    Choose an APK

    Use a sample that ships with the tool, or upload an app you are allowed to test.

  2. 2
    Pick the analyzers

    Static checks are on by default. Dynamic checks stay off until you connect a device and confirm you are allowed to test it.

  3. 3
    Read the report

    The scan runs in the background. This page stays responsive, then the report opens here.

Static analysis

Works from the APK alone. No device, no ADB, no extra setup.

  • Manifest flags, permissions, and exported components
  • Secrets, weak crypto, storage, and cleartext traffic
  • WebView settings, endpoints, and deep links

Dynamic analysis

Optional. These checks need a connected device and are left unchecked.

  • Device properties and install status
  • Launch, crash, and logcat review
  • Frida hooks for preferences and crypto
