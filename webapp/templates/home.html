What is androsec?

One place to inspect an APK and explain what you found.

androsec reads an application you are allowed to test. Static checks work from the file alone. Dynamic checks wait until you connect a device and confirm authorization. The report maps findings to OWASP MASVS, and the files never leave this computer.

Capabilities

What you can run

  1. 01

    Static and dynamic analysis

    {{ tool_count }} tools cover the manifest, permissions, components, secrets, crypto, storage, network, WebView, and a connected device.

  2. 02

    AI-powered finding review

    Open one finding from the report, enter your own API key, and keep the write-up on this machine.

  3. 03

    Decompile and rebuild

    Decode resources with apktool and Java with jadx, browse the tree, and rebuild the APK from the decoded project.
